# task3-insights · 任务三：专题深挖

负责人：任务三成员。

## 工作方式

1. 从 `contracts/anomaly_leads.csv` 选择 1 个以上 `status = open` 的线索；
2. 在 `contracts/claim_registry.csv` 登记主张，避免与任务二重复；
3. 复用任务二的 `shared/metrics/` 与 ECharts 组件，不另算一套口径；
4. 深挖结论回写 `anomaly_leads.csv` 的 `status`（`verified` / `rejected` / `handed_off`）。

## 边界

- 任务二负责“是什么、在哪里、有多大”；
- 任务三负责“为什么、意味着什么”；
- 同一个发现只能有一个主张者，重复时引用对方图号，不重复画图。

## 候选专题

S1 东道主效应、S2 口径的魔力、S3 地缘政治、S4 小代表团突破、S5 奖牌通货膨胀、S6 王者与传奇、S7 自选。
