> **一句话赛题** ：拿一份数据并不"干净"的真实奥运数据集——先驯服它，再用可视化讲出 128 年奥运史中最动人的故事。

## 一、赛题背景

1896 年，雅典。十几个代表团、两百余位运动员，没有一名女性。

2024 年，巴黎。206 个代表团、超过一万名运动员，女性占比 49.1%。

一百二十八年之间：两次世界大战让奥运三度停办（1916、1940、1944）；冷战把领奖台切成两个阵营；去殖民化让代表团从十几个变成两百多个；拔河、槌球、马车竞赛早已谢幕，滑板、冲浪、霹雳舞正在登场。

本赛题提供的，是一份覆盖 **1896–2024 年夏季奥运会全部参赛与奖牌记录** 的数据集。它忠实地记录了这段历史——**包括历史的疤痕** 。它不是教科书里那种"干净"数据：奖牌有两套口径、体育大类名称前后不一致、运动员姓名残缺不全、近两届的赛事字段还"闹了些脾气"。

我们 **刻意保留** 了这些真实世界数据的毛边。因为"从混沌数据到可信洞察"的完整旅程，正是数据分析的核心能力；而奥运百年史足够厚重，值得你为它做一次认真的可视化叙事。

你将完成三件事：

1. **体检** —— 审计数据质量，定义自己的统计口径（任务一）
2. **洞察** —— 完成百年全景分析与专题深挖（任务二、三）
3. **表达** —— 用可视化与叙事把发现变成作品（任务四，加分）

### 2.3 字段字典

| # | 字段 | 类型 | 含义 | ⚠️ 已知问题 |
| --- | --- | --- | --- | --- |
| 1 | `player_id` | 整数 | 运动员编号 | **不可靠** ：同一运动员在不同记录中可能对应多个 ID |
| 2 | `Name` | 文本 | 运动员姓名 | **严重不规范** ：存在截断、拼音顺序颠倒、括号残留、变音符号丢失、同名不同人被合并等问题 |
| 3 | `Sex` | 文本 | 性别 | M / F，仅此两值 |
| 4 | `Team` | 文本 | 队伍/代表队名称 | 含大量历史变体：俱乐部名、分队编号（如 `West Germany-1`）、混合队（如 1900 年 `Denmark/Sweden`）；取值多达 1,193 个 |
| 5 | `NOC` | 文本 | 国家/地区奥委会三字码 | 234 个，含大量已消失政体（URS、GDR、YUG…），是分析国家归属的 **首选字段** |
| 6 | `Year` | 整数 | 奥运会年份 | 2020 东京实际于 2021 年举行但记为 2020；包含 1906 |
| 7 | `Season` | 文本 | 赛季 | 恒为 `Summer`（本赛题仅夏奥会） |
| 8 | `City` | 文本 | 主办城市 | 1956 年同时存在 `Melbourne`（主体）与 `Stockholm`（马术） |
| 9 | `Sport` | 文本 | 体育大类 | 76 种取值， **2020 年前后口径漂移严重** ，见 2.4-Q2 |
| 10 | `Event` | 文本 | 小项 | 2020 年起大量使用泛化名称，见 2.4-Q3 |
| 11 | `Medal` | 文本 | 奖牌 | `Gold` / `Silver` / `Bronze` / `No medal`（无缺失值） |

> 📌 **特别提醒** ：本数据集 **不包含** 运动员年龄、身高、体重字段。若分析需要（如人口学背景），允许自行补充外部数据并声明来源（见 FAQ）。

### 2.4 数据口径与已知质量问题（参赛必读）

这份数据有六类"真实的毛病"。我们不隐藏它们——**识别并妥善处理它们，正是任务一的评分对象** 。以下每一条都经过复核，可直接作为你的检查清单起点。

**Q1 · 奖牌有两套口径。** 一行 = 一名运动员 × 一个小项。男子足球冠军队 18 名球员 = 18 行金牌记录，而官方奖牌榜只计 1 枚。全数据集 38,818 行奖牌记录对应的是"运动员行口径"，与官方"小项口径"差异巨大（例：2024 年美国官方 40 金，本数据中金牌行有 131 行；荷兰官方 15 金，金牌行却有 67 行——曲棍球等团体项目的威力）。 **你必须声明自己采用哪种口径** ，推荐两种口径对比呈现。

**Q2 · 体育大类名称漂移。** 2020 年起（数据来源切换所致），同一运动的大类名称发生变化：`Gymnastics`（1896–2016）→ `Artistic Gymnastics` + `Trampoline Gymnastics`（2020–）；`Cycling`（–2016）→ `Cycling Road` / `Cycling Track` / `Cycling Mountain Bike` / `Cycling BMX Racing` / `Cycling BMX Freestyle`（2020–）；`Canoeing` → `Canoe Sprint` / `Canoe Slalom`；`Equestrianism` → `Equestrian`；`Synchronized Swimming` → `Artistic Swimming`。此外 2024 年还有 89 行的 Sport 字段是逗号拼接的跨项写法（如 `Cycling Road, Triathlon`）。做任何"按运动统计"的分析前，先做一张 **大类归一映射表** 。

**Q3 · 小项命名 2020 年起泛化。** 2016 年及以前，Event 形如 `Football Men's Football`、`Judo Men's Extra-Lightweight`；2020/2024 两届则有约 6,700 行（约 22–23%）的 Event 是 `Men` / `Women` / `Men Team` / `Relay Only Athlete` 之类泛化值，仅凭 Event 无法还原具体小项（需结合 Sport、Sex 字段，或接受降维到"大类 × 性别"的粒度）。处理策略自行决定，但须在口径说明中写明。

**Q4 · 姓名与 ID 不可靠。** `player_id` 平均每 ID 只出现 1.1 次（同一人多次参赛会拿到不同 ID）；`Name` 则存在两类相反的问题——**同一人多种写法** （如史上奖牌最多的游泳运动员在本数据中写作 `Michael Ii`，其姓名在源数据处理时被截断，28 行奖牌、23 金）与 **不同人被错误合并** （如 `Charles Jr.` 跨越 1904–1992 年，显然是多人的记录混入了同一姓名）。中文等非罗马姓名还存在拼音顺序不统一的问题。做"运动员个体"分析前，你需要一套自己的实体识别/归并策略，或选择规避个体粒度的选题。

**Q5 · 历史特殊记录。**

- **1906 年届次** （雅典"届间奥运会"）：IOC 现行口径不承认，本数据含 458 行奖牌记录——是否纳入分析由你决定，须声明；
- **1956 年双城** ：马术赛事因澳大利亚检疫法在斯德哥尔摩举行，数据中当年有两个 City；
- **政体变迁** ：URS（苏联，1952–1988）→ EUN（独联体联队，1992）→ RUS → ROC（2020）→ AIN（2024 个人中立运动员）；FRG/GDR（两德，1968–1988）→ GER；YUG → SCG → …；EOR（难民代表团，2024 年获该队历史首枚奖牌——顺带一提，本数据中该行记录的运动员姓名与官方公布不一致，欢迎交叉验证）；
- **抵制潮** ：1980 年莫斯科（美国缺席，仅 80 个代表团）、1984 年洛杉矶（苏联、东德缺席，140 个代表团）。

**Q6 · 团体项目与并列奖牌。** 数据中有 5,080 组"同届 × 同小项 × 同奖牌多行"的记录（团体项目为主，也混有并列奖牌）；另有 34 个小项只颁发了一种奖牌——最著名的如 **1908 年男子 400 米** ：因判罚争议，最终只颁发了金牌，这是奥运史上唯一一次"走跑"夺冠（walkover）。并列奖牌、早期无铜牌等历史细节都会影响"金银铜应当相等"的天真假设（数据中金 13,002 / 银 12,746 / 铜 13,070，并不相等）。

## 九、FAQ

**Q：可以用外部数据吗？** A：可以（人口、GDP、人类发展指数等），须逐项声明来源与合并方式；但核心结论必须能仅凭赛题数据集复现。

**Q：1906 年那届到底算不算？** A：由你决定。纳入或不纳入都合理，唯一的硬性要求是在口径说明中写明并全文一致。

**Q：团体项目奖牌怎么算才对？** A：没有唯一正确答案。最低要求：采用一种明确口径；推荐：两种口径并做对比（这本身就是 S2 专题）。

**Q：为什么 2020 东京写的是 2020？实际不是 2021 年办的吗？** A：东京奥运会因疫情延期至 2021 年举行，但届次名称保留"2020 东京"。数据沿用官方年份，处理时请留意。

**Q：2024 年 Event 字段很多 "Men / Women"，是不是坏数据？** A：是已知的数据源切换问题（2.4-Q3），属于本赛题"数据体检"环节的一部分。按你的策略处理并声明即可。

**Q：数据里能做运动员个体的轨迹分析吗？** A：可以，但需要先解决姓名/ID 不可靠问题（2.4-Q4），或接受不完美的近似并评估其影响。这也是 S6 专题的挑战所在。

**Q：工具/语言有限制吗？** A：没有。静态图、交互 Dashboard、BI 工具均可；评分看最终的分析与表达质量。

**Q：报告可以超过 20 页吗？** A：不可以，超过部分评审不再阅读。附录（如完整映射表）可另附文件并在正文中引用。
